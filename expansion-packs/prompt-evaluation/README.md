# Prompt Evaluation

Analyzes your prompts and helps you become a better prompter.

## What It Does

- Scores your prompts from the session (X/5)
- Highlights your weakest prompts with specific issues
- Suggests rewrites for improvement
- Gives quick tips for better prompting

## Install

Copy the command file to your Claude commands directory:

```bash
cp evaluate-prompts.md ~/.claude/commands/
```

## Usage

```
/evaluate-prompts
```

Best used mid-session to course-correct, or at session end.
